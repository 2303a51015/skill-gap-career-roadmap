# User Manual & Operator Guide

## Project Title
**AI-Based Skill Gap Analysis and Personalized Career Roadmap Generation System for a Given Resume**

---

## 1. Introduction

Welcome to **CareerPath AI**, a web-based career intelligence platform designed for students, fresh graduates, and career changers. This guide walks you through setting up, running, and using all features of the application.

---

## 2. System Requirements & Quick Start

### Prerequisites
- **Operating System:** Windows 10/11, macOS, or Linux.
- **Node.js:** v18.0.0 or higher (v20+ LTS recommended; tested on v26.13.0).
- **Web Browser:** Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Starting the Application
Open a terminal in the root project folder:

```bash
# 1. Install all dependencies (Backend + Frontend)
npm run install:all

# 2. Configure environment (Optional for Gemini API)
# In backend/.env, set your GEMINI_API_KEY from https://aistudio.google.com/app/apikey
# If you don't have an API key, set AI_PROVIDER=mock for offline demo mode!

# 3. Start development servers concurrently
npm run dev
```

The application will be live at:
- **Frontend Dashboard:** [http://localhost:5173](http://localhost:5173)
- **Backend API & Health:** [http://localhost:5000/api/health](http://localhost:5000/api/health)

## 3. Step-by-Step Feature Walkthrough

### 3.1. Landing Page (`/`)
- Navigate to [http://localhost:5173](http://localhost:5173).
- Review the project overview, three-step workflow, and scoring breakdown.
- Click **"Analyze My Resume Now"** to open the assessment form.

### 3.2. Resume & Job Description Input (`/analyze`)
1. **Resume Ingestion:**
   - Drag and drop your resume file into the upload zone, or click **"browse"** to select a file (`.pdf`, `.docx`, or `.txt` up to 5MB).
   - Once selected, click **"Preview Extracted Text"** to verify that your resume's text is correctly parsed.
2. **Target Role & Job Posting:**
   - Enter your target title (e.g., *Full Stack Software Engineer*).
   - Paste the job description into the text area.
3. **Preferences & Preparation Parameters:**
   - Select your current experience stage (*Student*, *Fresher*, *Entry Level*, *Experienced*).
   - Adjust the **Daily Learning Time** slider (e.g., 2.5 hours/day).
   - Choose your **Target Duration** (e.g., 8 weeks).
   - Select your **Preferred Learning Style** (*Hands-on Projects*, *Reading*, *Video*, or *Mixed*).
4. **Quick Demo Shortcut:**
   - If you want an immediate test without locating a resume file, click the **"Quick Demo: Load Sample Data"** button at the top right to automatically fill high-quality sample fixtures.
5. **Execution:**
   - Check the Privacy & AI Analysis Consent checkbox.
   - Click **"Analyze My Skill Gap & Generate Career Roadmap"**.
   - Watch the animated loading overlay as each processing stage executes.

### 3.3. Analysis Dashboard (`/dashboard/:id`)
- **Overall Match Score:** Examine your circular progress gauge and the 70% / 15% / 15% component scores.
- **Skill Distribution Donut:** See the visual proportion of Matching, Partial, and Missing skills.
- **Domain Category Bar Chart:** View your technical coverage across Languages, Frameworks, Databases, and Cloud.
- **Skill Evidence Matrix:** Filter between *Matching*, *Partial*, *Missing*, and *Additional* skills to read explicit resume evidence and job requirements.
- **Resume Optimization:** Review actionable suggestions to enhance your resume for ATS screening using Google's X-Y-Z metric formula.

### 3.4. Personalized Career Roadmap (`/roadmap/:id`)
- Review week-by-week milestones tailored to your duration and daily hours.
- Each milestone contains:
  - Estimated learning hours and priority level.
  - Bulleted learning objectives.
  - Verified learning resources with direct external links.
  - Hands-on practical project deliverable.
  - Completion criteria.
- **Interactive Tracking:** Change a milestone's status dropdown between `⚪ Not Started`, `🔵 In Progress`, and `🟢 Completed`. Your progress updates the progress bar and is saved directly to the SQLite database.

### 3.5. Reports & History (`/history`)
- View a chronological list of all previous assessments.
- Click **"Dashboard"** or **"Roadmap"** to reopen any saved session.
- Click **"Download PDF"** to get a formatted, multi-page vector PDF report generated by the server.
- Click the trash can icon to permanently delete an analysis record and its milestones.

## 4. Troubleshooting Guide

| Issue | Likely Cause | Solution |
| :--- | :--- | :--- |
| **"API Offline" badge in Navbar** | Backend server is not running on port 5000. | In a terminal, run `npm --prefix backend run dev` to start the backend. |
| **"Gemini API Key is not configured"** | Missing or placeholder key in `backend/.env`. | Get a free key at [Google AI Studio](https://aistudio.google.com/app/apikey) and put it in `GEMINI_API_KEY`, OR set `AI_PROVIDER=mock` in `.env` for offline demonstration. |
| **"Document contains insufficient readable text"** | Uploaded a scanned image PDF without OCR. | Upload a text-based PDF, DOCX, or plain text document with selectable text. |
| **"File size exceeds 5MB limit"** | Document is larger than 5MB. | Compress or convert the document to a standard PDF or DOCX file under 5MB. |
| **CORS error in browser console** | Accessing from an unauthorized URL. | By default, `http://localhost:5173` is permitted. Ensure you access the frontend at port 5173. |
